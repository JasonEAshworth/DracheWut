# Python Pygame Game

An unfinished tile-based game built with Python 2.7 and Pygame (a personal project that was
never completed). Includes a tile map editor and some early networking experiments.

## Layout

- `Map_Editor/`: a tile map editor
- `Player Class/`, `player-world/`: gameplay code
- `networking_start/`: early networking experiments
- `Artwork/`, `Sound/`: art and audio assets
- `docs/`, `Helpful Notes.txt`: notes

## Run it

Requires Python 2.7 and Pygame (it predates Python 3).
